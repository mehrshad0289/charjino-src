# Admin Charjino

پنل مدیریت **چارژینو** — Next.js 16، React 19، TypeScript، RTL فارسی.

فروشگاه: `Frontend-charjino` روی `:3001`  
بک‌اند لاراول: `Backend-charjino` روی `:3000/api`

ورود ادمین از `POST /api/auth/admin/login` خوانده می‌شود. پیش‌فرض توسعه: `admin@charjino.local` / `charjino-admin`.

## شروع

```bash
copy .env.example .env.local
npm install
npm run dev
```

پیش‌فرض: [http://127.0.0.1:3002](http://127.0.0.1:3002)
